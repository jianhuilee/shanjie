# Shanjie fcitx5 Addon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Linux fcitx5 input method that types Zhuyin through the existing Shanjie Rust core, usable as a daily driver.

**Architecture:** A C++ addon in `linux/fcitx5/` links `libcore.a` through `core/include/shanjie.h`. Shell logic lives in an fcitx5-free static library (`keymap`, `utf`, `core_engine`, `rerank_runner`, `session`) tested against the real core with a fake client; `engine.cpp` is a thin fcitx5 adapter. The core is not modified.

**Tech Stack:** C++20, CMake, fcitx5 5.1 (`Fcitx5Core`), Rust core as a static library, CTest with plain test executables.

**Spec:** `docs/superpowers/specs/2026-11-12-fcitx5-port-design.md`

---

## Background the implementer needs

- **The core.** `core/include/shanjie.h` is the whole API; its comments are the function reference. `docs/spec/c-abi.md` has the return codes (0 ok, 1 NULL, 2 invalid, 3 load failed, 4 internal, 5 no change) and ownership rules. Every non-NULL `ShanjieOutput*` must be freed exactly once with `shanjie_output_free`.
- **Privacy rule R2.** Never log or print output contents, candidates, model paths or job pointers. Logs carry a static string and a return code only. Test failure messages print the failed condition's source text, never values.
- **Threading.** Every engine call is on one thread. Only `shanjie_rerank_run` and `shanjie_rerank_free` may run elsewhere.
- **Key encoding.** `ShanjieKey.ch` is the unshifted US-ANSI keycap character. The shell reads the physical key (evdev code), not the keysym, so the XKB layout does not matter. fcitx5's `Key::code()` is the evdev code plus 8.
- **Models.** `data/lm/` must hold the eight release files (`CONTRIBUTING.md` lists the `curl` commands). Tests that need them fail with a message; they do not skip.
- **Build directory.** `build/fcitx5` (`/build/` is git-ignored).
- **Commands**, from the repository root:

  ```sh
  cmake -S linux/fcitx5 -B build/fcitx5 -DCMAKE_BUILD_TYPE=Release -DFCITX_INSTALL_USE_FCITX_SYS_PATHS=ON
  cmake --build build/fcitx5 -j
  ctest --test-dir build/fcitx5 --output-on-failure
  ```

`linux/fcitx5/src/utf.cpp`:

```cpp
#include "utf.h"

#include <vector>

namespace shanjie {

namespace {
// Length in bytes of the UTF-8 character starting with `c`; 1 for a stray continuation byte.
size_t charLen(unsigned char c) {
    if (c < 0x80) return 1;
    if ((c >> 5) == 0x6) return 2;
    if ((c >> 4) == 0xE) return 3;
    if ((c >> 3) == 0x1E) return 4;
    return 1;
}
} // namespace

size_t utf16ToByteOffset(std::string_view s, uint32_t units) {
    size_t i = 0;
    uint32_t u = 0;
    while (i < s.size() && u < units) {
        const size_t len = charLen(static_cast<unsigned char>(s[i]));
        const uint32_t width = len == 4 ? 2 : 1;
        if (u + width > units) break;
        if (i + len > s.size()) return s.size();
        i += len;
        u += width;
    }
    return i;
}

std::string textBefore(std::string_view text, uint32_t cursorChars, uint32_t maxChars) {
    std::vector<size_t> starts;
    size_t i = 0;
    while (i < text.size() && starts.size() < cursorChars) {
        starts.push_back(i);
        i += charLen(static_cast<unsigned char>(text[i]));
    }
    const size_t end = i < text.size() ? i : text.size();
    if (starts.empty() || maxChars == 0) return {};
    const size_t from = starts.size() > maxChars ? starts[starts.size() - maxChars] : 0;
    return std::string(text.substr(from, end - from));
}

} // namespace shanjie
```

```cpp
#pragma once
#include <cstdint>
#include <optional>

#include "shanjie.h"

namespace shanjie {

// ShanjieKey.kind values (core/include/shanjie.h).
enum Kind : uint32_t {
    KindChar = 1, KindSpace = 2, KindEnter = 3, KindBackspace = 4, KindDelete = 5, KindEsc = 6,
    KindLeft = 7, KindRight = 8, KindUp = 9, KindDown = 10, KindHome = 11, KindEnd = 12, KindTab = 13,
    KindPageUp = 14, KindPageDown = 15,
};

// ShanjieKey.modifiers bits. Alt is the core's Option, Super is its Command.
enum Mod : uint32_t { ModShift = 1, ModControl = 2, ModAlt = 4, ModSuper = 8, ModCapsLock = 16 };

// A physical key press: the evdev code (linux/input-event-codes.h, i.e. the X keycode minus 8) and
// the modifier state. 0 means "unknown key".
struct KeyInput {
    uint32_t evdev = 0;
    bool shift = false, ctrl = false, alt = false, super = false, caps = false;
};

uint32_t modifierBits(const KeyInput &in);

// The key for the core, or nullopt for a key outside the tables (keypad, function keys, Page Up/Down,
// modifiers, unknown). The character is the unshifted US-ANSI keycap.
std::optional<ShanjieKey> translate(const KeyInput &in);

// Page Up / Page Down as kinds 14 / 15, only without any modifier. The caller sends them only while the
// vertical candidate window is open.
std::optional<ShanjieKey> translatePage(const KeyInput &in);

// True for Shift, Control, Alt, Super and Caps Lock themselves.
bool isModifierKey(uint32_t evdev);

// For frontends that give no keycode: the evdev code of the US-layout key that produces this X keysym,
// or 0. Shifted symbols map to their key ('!' to the 1 key).
uint32_t evdevFromKeysym(uint32_t keysym);

} // namespace shanjie
```

```cpp
#include "keymap.h"

#include <cstring>

namespace shanjie {

namespace {

// Rows of the US-ANSI keyboard by evdev code: the first code of the row and its unshifted characters.
struct Row { uint32_t first; const char *plain; const char *shifted; };
const Row kRows[] = {
    {2, "1234567890-=", "!@#$%^&*()_+"},
    {16, "qwertyuiop[]", "QWERTYUIOP{}"},
    {30, "asdfghjkl;'`", "ASDFGHJKL:\"~"},
    {43, "\\", "|"},
    {44, "zxcvbnm,./", "ZXCVBNM<>?"},
};

uint32_t charFor(uint32_t evdev) {
    for (const Row &row : kRows) {
        const uint32_t n = static_cast<uint32_t>(std::strlen(row.plain));
        if (evdev >= row.first && evdev < row.first + n)
            return static_cast<unsigned char>(row.plain[evdev - row.first]);
    }
    return 0;
}

uint32_t kindFor(uint32_t evdev) {
    switch (evdev) {
    case 57: return KindSpace;
    case 28: case 96: return KindEnter;
    case 14: return KindBackspace;
    case 111: return KindDelete;
    case 1: return KindEsc;
    case 105: return KindLeft;
    case 106: return KindRight;
    case 103: return KindUp;
    case 108: return KindDown;
    case 102: return KindHome;
    case 107: return KindEnd;
    case 15: return KindTab;
    default: return 0;
    }
}

} // namespace

uint32_t modifierBits(const KeyInput &in) {
    return (in.shift ? ModShift : 0u) | (in.ctrl ? ModControl : 0u) | (in.alt ? ModAlt : 0u) |
           (in.super ? ModSuper : 0u) | (in.caps ? ModCapsLock : 0u);
}

std::optional<ShanjieKey> translate(const KeyInput &in) {
    if (const uint32_t ch = charFor(in.evdev)) return ShanjieKey{KindChar, ch, modifierBits(in)};
    if (const uint32_t kind = kindFor(in.evdev)) return ShanjieKey{kind, 0, modifierBits(in)};
    return std::nullopt;
}

std::optional<ShanjieKey> translatePage(const KeyInput &in) {
    if (modifierBits(in) != 0) return std::nullopt;
    if (in.evdev == 104) return ShanjieKey{KindPageUp, 0, 0};
    if (in.evdev == 109) return ShanjieKey{KindPageDown, 0, 0};
    return std::nullopt;
}

bool isModifierKey(uint32_t evdev) {
    switch (evdev) {
    case 29: case 97:   // Control
    case 42: case 54:   // Shift
    case 56: case 100:  // Alt
    case 125: case 126: // Super
    case 58:            // Caps Lock
        return true;
    default:
        return false;
    }
}

uint32_t evdevFromKeysym(uint32_t keysym) {
    switch (keysym) {
    case 0x20: return 57;                 // space
    case 0xff08: return 14;               // BackSpace
    case 0xff09: case 0xfe20: return 15;  // Tab, ISO_Left_Tab
    case 0xff0d: return 28;               // Return
    case 0xff8d: return 96;               // KP_Enter
    case 0xff1b: return 1;                // Escape
    case 0xff50: return 102;              // Home
    case 0xff51: return 105;              // Left
    case 0xff52: return 103;              // Up
    case 0xff53: return 106;              // Right
    case 0xff54: return 108;              // Down
    case 0xff55: return 104;              // Page_Up
    case 0xff56: return 109;              // Page_Down
    case 0xff57: return 107;              // End
    case 0xffff: return 111;              // Delete
    default: break;
    }
    if (keysym < 0x21 || keysym > 0x7e) return 0;
    const char c = static_cast<char>(keysym);
    for (const Row &row : kRows) {
        for (uint32_t i = 0; row.plain[i]; i++)
            if (row.plain[i] == c || row.shifted[i] == c) return row.first + i;
    }
    return 0;
}

} // namespace shanjie
```

```cpp
// A copy of ShanjieOutput. Holds what the person typed: never log it, never give it a stream operator.
struct Output {
    bool handled = false;
```

```cpp
#include <bit>

namespace shanjie {

namespace {

// Copies every field and frees the core's output in the same call (docs/spec/c-abi.md §5.1).
Output copyAndFree(ShanjieOutput *o) {
    Output out;
    out.handled = o->handled == 1;
    out.commit = o->commit;
    out.preedit = o->preedit;
    out.cursorUtf16 = o->cursor_utf16;
    out.candidates.reserve(o->candidate_count);
    for (uint32_t i = 0; i < o->candidate_count; i++) out.candidates.emplace_back(o->candidates[i]);
    out.selected = o->candidate_selected;
    out.columns = o->candidate_columns;
    out.first = o->candidate_first;
    out.total = o->candidate_total;
    out.vertical = o->candidate_vertical;
    out.englishStartUtf16 = o->english_run_utf16_start;
    out.englishLenUtf16 = o->english_run_utf16_len;
    shanjie_output_free(o);
    return out;
}

template <typename F>
Result call(F &&f) {
    ShanjieOutput *o = nullptr;
    Result r;
    r.code = f(&o);
    if (r.code == 0 && o) r.out = copyAndFree(o);
    return r;

ShanjieEngine *CoreEngine::create(const Paths &paths, uint32_t layout, uint32_t packs) {
    auto make = [&](uint32_t mask) -> ShanjieEngine * {
        ShanjieEngine *e = nullptr;
        const int32_t code =
            shanjie_engine_new_packs(paths.lexicon.c_str(), layout, paths.packs.c_str(), mask, &e);
        note("shanjie_engine_new_packs", code);
        return code == 0 ? e : nullptr;
    };
    if (ShanjieEngine *e = make(packs)) return e;
    if (packs == 0) return nullptr;
    // A pack may be the problem (docs/spec/macos-shell.md §2.1): try without packs, then drop one
    // enabled pack at a time and keep the first set that builds.
    ShanjieEngine *bare = make(0);
    if (!bare) return nullptr;
    if (std::popcount(packs) == 1) return bare;
    for (uint32_t bit = 1; bit <= SHANJIE_PACK_BEAUTY; bit <<= 1) {
        if (!(packs & bit)) continue;
        shanjie_engine_free(bare);
        bare = nullptr;
        if (ShanjieEngine *e = make(packs & ~bit)) return e;
    }
    return make(0);
}

    shanjie_engine_free(engine_);
    engine_ = nullptr;
    hasModel_ = false;
    engine_ = create(paths, config.layout, config.packs);
    if (!engine_) return false;

    if (!paths.lm.empty()) {
        int32_t code = shanjie_engine_load_lm(engine_, (paths.lm + "/bigram.sjlm").c_str());
        note("shanjie_engine_load_lm", code);
        if (code == 0) {
            hasModel_ = true;
            code = shanjie_engine_load_tinylm(engine_, (paths.lm + "/tinylm.sjtl").c_str());
```

```cpp
#include <atomic>
#include <chrono>

#include <cstdint>

namespace shanjie {

// Runs rerank jobs off the key path (docs/spec/semantic-rerank.md §6). submit, waitFor, cancelAll and
// the destructor are called on the main thread. A job is touched by one thread at a time.
class RerankRunner {
public:
    // Runs the callback on the main thread, later. Must be callable from any thread.
    using Post = std::function<void(std::function<void()>)>;
    // Receives a finished job on the main thread. The callee owns it and must free it.
    using Done = std::function<void(ShanjieRerankJob *)>;

    RerankRunner(Post post, Done done);
    ~RerankRunner();
    RerankRunner(const RerankRunner &) = delete;
    RerankRunner &operator=(const RerankRunner &) = delete;

    // Takes ownership. Replaces (and frees) a job that is queued but not started.
    void submit(ShanjieRerankJob *job);
    // Waits until no job is queued or running, at most `timeout`. Returns the finished job if there is
    // one (the caller owns it), else nullptr. A job returned here is not delivered through Done.
    ShanjieRerankJob *waitFor(std::chrono::milliseconds timeout);
    // Frees queued and finished jobs; a running job is freed when it ends and never delivered.
    void cancelAll();

private:
    void loop();
    void drain();

    Post post_;
    Done done_;
    std::mutex mutex_;
    std::condition_variable cv_;
    ShanjieRerankJob *queued_ = nullptr;
    ShanjieRerankJob *finished_ = nullptr;
    bool running_ = false;
    bool stop_ = false;
    uint64_t epoch_ = 0;
    std::shared_ptr<std::atomic<bool>> alive_ = std::make_shared<std::atomic<bool>>(true);
    std::thread thread_;
};

} // namespace shanjie
```

```cpp
// A stand-in for the main loop: callbacks queue up and run when the test pumps.
struct Pump {
    std::mutex m;
    std::vector<std::function<void()>> q;
    void post(std::function<void()> f) {
        std::lock_guard<std::mutex> l(m);
        q.push_back(std::move(f));
    }
    int run() {
        std::vector<std::function<void()>> take;
        {
            std::lock_guard<std::mutex> l(m);
            take.swap(q);
        }
        for (auto &f : take) f();
        return static_cast<int>(take.size());
    }
    // Pumps until `done` or two seconds pass.
    template <typename P> bool until(P done) {
        for (int i = 0; i < 400 && !done(); i++) {
            run();
            if (!done()) std::this_thread::sleep_for(5ms);
        }
        return done();
```

```cpp
#include "rerank_runner.h"

namespace shanjie {

RerankRunner::RerankRunner(Post post, Done done)
    : post_(std::move(post)), done_(std::move(done)), thread_([this] { loop(); }) {}

RerankRunner::~RerankRunner() {
    {
        std::lock_guard<std::mutex> lock(mutex_);
        stop_ = true;
    }
    cv_.notify_all();
    thread_.join();
    *alive_ = false; // callbacks already posted must not touch this object
    shanjie_rerank_free(queued_);
    shanjie_rerank_free(finished_);
}

void RerankRunner::submit(ShanjieRerankJob *job) {
    if (!job) return;
    {
        std::lock_guard<std::mutex> lock(mutex_);
        shanjie_rerank_free(queued_);
        queued_ = job;
    }
    cv_.notify_all();
}

ShanjieRerankJob *RerankRunner::waitFor(std::chrono::milliseconds timeout) {
    std::unique_lock<std::mutex> lock(mutex_);
    cv_.wait_for(lock, timeout, [this] { return !running_ && !queued_; });
    ShanjieRerankJob *job = finished_;
    finished_ = nullptr;
    return job;
}

void RerankRunner::cancelAll() {
    std::lock_guard<std::mutex> lock(mutex_);
    ++epoch_;
    shanjie_rerank_free(queued_);
    queued_ = nullptr;
    shanjie_rerank_free(finished_);
    finished_ = nullptr;
}

void RerankRunner::loop() {
    std::unique_lock<std::mutex> lock(mutex_);
    for (;;) {
        cv_.wait(lock, [this] { return stop_ || queued_; });
        if (stop_) return;
        ShanjieRerankJob *job = queued_;
        queued_ = nullptr;
        running_ = true;
        const uint64_t epoch = epoch_;
        lock.unlock();

        shanjie_rerank_run(job); // a failed run leaves no result; apply then reports "no change"

        lock.lock();
        running_ = false;
        const bool publish = epoch == epoch_ && !stop_;
        if (publish) {
            shanjie_rerank_free(finished_); // an older result is stale once a newer job ran
            finished_ = job;
        } else {
            shanjie_rerank_free(job);
        }
        cv_.notify_all();
        if (publish) {
            lock.unlock();
            post_([this, alive = alive_] {
                if (*alive) drain();
            });
            lock.lock();
        }
    }
}

void RerankRunner::drain() {
    ShanjieRerankJob *job;
    {
        std::lock_guard<std::mutex> lock(mutex_);
        job = finished_;
        finished_ = nullptr;
    }
    if (job) done_(job);
}

} // namespace shanjie
```

```cpp
#include "session.h"

#include <chrono>

#include "utf.h"

namespace shanjie {

Session::Session(Paths paths, Config config, RerankRunner::Post post, CoreEngine::Log log)
    : paths_(std::move(paths)), config_(config), log_(std::move(log)), engine_(log_) {
    engine_.build(paths_, config_);
    runner_ = std::make_unique<RerankRunner>(std::move(post),
                                             [this](ShanjieRerankJob *job) { onRerankDone(job); });
}

Session::~Session() = default;

void Session::claim(Client &client) {
    if (owner_ == &client) return;
    if (composing_) {
        if (owner_) {
            finish(*owner_, true); // the composition goes back to its own client
        } else {
            engine_.reset(1);
            composing_ = false;
            lastPreedit_.reset();
        }
    }
    owner_ = &client;
}

bool Session::handleKey(Client &client, const KeyInput &in) {
    if (!engine_.ready()) return false;
    // A modifier pressed alone is not a key for the core and must not end the composition.
    if (isModifierKey(in.evdev)) return false;
    claim(client);
    if (client.isPassword()) {
        finish(client, false);
        return false;
    }
    engine_.setLearning(config_.learning);

    std::optional<ShanjieKey> key = translate(in);
    if (!key && lastVertical_ == 1) key = translatePage(in);
    if (!key) {
        // Outside the tables: send the composition, then let the application have the key.
        finish(client, true);
        return false;
    }

    if (!composing_) {
        const std::optional<std::string> left = client.leftContext();
        engine_.setLeftContext(left ? left->c_str() : nullptr);
    }
    if (key->kind == KindEnter && composing_) {
        // Let a running rerank catch up, so what is sent is what it would have shown.
        if (ShanjieRerankJob *job = runner_->waitFor(std::chrono::milliseconds(kEnterRerankWaitMs)))
            onRerankDone(job);
    }

    const Result r = engine_.key(*key);
    if (r.code != 0) {
        fail(client, "shanjie_engine_key", r.code);
        return false;
    }
    // Pure pass-through: the core changed nothing, so the client is not touched.
    if (!r.out.handled && r.out.commit.empty()) return false;
    apply(client, r.out);
    return r.out.handled;
}

void Session::pick(Client &client, uint32_t index) {
    if (!engine_.ready() || owner_ != &client) return;
    const Result r = engine_.pick(index);
    if (r.code == 2) return; // stale click: state unchanged
    if (r.code != 0) {
        fail(client, "shanjie_engine_pick", r.code);
        return;
    }
    apply(client, r.out);
}

void Session::finish(Client &client, bool commit) {
    if (!engine_.ready() || owner_ != &client || !composing_) return;
    const Result r = engine_.reset(commit ? 0 : 1);
    if (r.code != 0) {
        fail(client, "shanjie_engine_reset", r.code);
        return;
    }
    apply(client, r.out);
}

void Session::clientDestroyed(Client &client) {
    if (owner_ != &client) return;
    owner_ = nullptr;
    if (composing_ && engine_.ready()) engine_.reset(1);
    composing_ = false;
    lastVertical_ = 0;
    lastPreedit_.reset();
}

void Session::setConfig(const Config &config) {
    if (owner_) finish(*owner_, true);
    const bool rebuild = CoreEngine::needsRebuild(config_, config) || !engine_.ready();
    config_ = config;
    if (rebuild) {
        runner_->cancelAll(); // jobs of the old engine must not reach the new one
        engine_.build(paths_, config_);
        composing_ = false;
        lastVertical_ = 0;
        lastPreedit_.reset();
    } else {
        engine_.applySettings(config_);
    }
}

void Session::apply(Client &client, const Output &out) {
    if (!out.commit.empty()) client.commit(out.commit);

    if (out.preedit.empty()) {
        if (lastPreedit_) {
            client.clearPreedit();
            lastPreedit_.reset();
        }
    } else {
        const size_t cursor = utf16ToByteOffset(out.preedit, out.cursorUtf16);
        const size_t enStart = utf16ToByteOffset(out.preedit, out.englishStartUtf16);
        const size_t enEnd = utf16ToByteOffset(out.preedit, out.englishStartUtf16 + out.englishLenUtf16);
        auto now = std::make_tuple(out.preedit, cursor, enStart, enEnd);
        // A commit replaced the client's preedit, so it is always sent again after one.
        if (!out.commit.empty() || !lastPreedit_ || *lastPreedit_ != now) {
            client.setPreedit(out.preedit, cursor, enStart, enEnd);
            lastPreedit_ = std::move(now);
        }
    }
    composing_ = !out.preedit.empty();
    lastVertical_ = out.vertical;

    if (out.candidates.empty()) {
        client.hideCandidates();
    } else {
        client.showCandidates(out);
    }
    if (ShanjieRerankJob *job = engine_.takeJob()) runner_->submit(job);
}

void Session::fail(Client &client, const char *what, int32_t code) {
    if (log_) log_(what, code);
    engine_.reset(1); // the core resets itself only on code 4
    if (lastPreedit_) client.clearPreedit();
    client.hideCandidates();
    lastPreedit_.reset();
    composing_ = false;
    lastVertical_ = 0;
}

void Session::onRerankDone(ShanjieRerankJob *job) {
    const Result r = engine_.ready() ? engine_.applyJob(job) : Result{SHANJIE_NO_CHANGE, {}};
    shanjie_rerank_free(job);
    if (r.code == SHANJIE_NO_CHANGE) return;
    if (!owner_) return;
    if (r.code != 0) {
        fail(*owner_, "shanjie_engine_rerank_apply", r.code);
        return;
    }
    apply(*owner_, r.out);
}

} // namespace shanjie
```

```cpp
    // selected -1 with candidates is the prediction row before it is entered: no highlight, and only
    // the first cell is marked, with the Tab glyph (docs/spec/prediction.md §8).
    const bool passiveRow = out.selected < 0;

        if (passiveRow) {

            labels_.emplace_back(std::to_string(i + 1) + ". ");
        }
    }
```

```cpp
// The directory that holds `file` under fcitx5's data directories (user first, then system), or "".
std::string dirHolding(const char *file) {
    const std::string found = StandardPath::global().locate(StandardPath::Type::PkgData, file);
    return found.empty() ? std::string() : std::filesystem::path(found).parent_path().string();
}

shanjie::Paths findPaths() {
    shanjie::Paths p;
    p.lexicon = dirHolding("shanjie/lexicon/mcbpmf-data.txt");
    p.packs = dirHolding("shanjie/packs/acg-add.tsv");
    // A missing pack file adds nothing, but the directory argument must not be empty.
    if (p.packs.empty() && !p.lexicon.empty())
        p.packs = (std::filesystem::path(p.lexicon).parent_path() / "packs").string();
    // The model files are paired by hash, so one directory serves them all.
    p.lm = dirHolding("shanjie/lm/bigram.sjlm");
    const std::string user = StandardPath::global().userDirectory(StandardPath::Type::PkgData);
    if (!user.empty() && fs::makePath(user + "/shanjie")) p.learn = user + "/shanjie/learn";
    return p;
}

// ---- ShanjieClient

ShanjieClient::~ShanjieClient() {
    if (auto *session = engine_->session()) session->clientDestroyed(*this);
}

void ShanjieClient::commit(const std::string &text) { ic_->commitString(text); }

void ShanjieClient::setPreedit(const std::string &text, size_t cursor, size_t englishStart, size_t englishEnd) {
    const TextFormatFlags plain = TextFormatFlag::Underline;
    Text preedit;
    if (englishEnd > englishStart && englishEnd <= text.size()) {
        TextFormatFlags english = TextFormatFlag::Underline;
        english |= TextFormatFlag::Bold;
        preedit.append(text.substr(0, englishStart), plain);
        preedit.append(text.substr(englishStart, englishEnd - englishStart), english);
        preedit.append(text.substr(englishEnd), plain);
    } else {
        preedit.append(text, plain);
    }
    preedit.setCursor(static_cast<int>(cursor));
    auto &panel = ic_->inputPanel();
    if (ic_->capabilityFlags().test(CapabilityFlag::Preedit)) {
        panel.setClientPreedit(preedit);
        ic_->updatePreedit();
    } else {
        panel.setPreedit(preedit);
    }
    ic_->updateUserInterface(UserInterfaceComponent::InputPanel);
}

void ShanjieClient::clearPreedit() {
    auto &panel = ic_->inputPanel();
    panel.setClientPreedit(Text());
    panel.setPreedit(Text());
    ic_->updatePreedit();
    ic_->updateUserInterface(UserInterfaceComponent::InputPanel);
}

void ShanjieClient::showCandidates(const shanjie::Output &out) {
    ic_->inputPanel().setCandidateList(std::make_unique<ShanjieCandidateList>(engine_, out));
    ic_->updateUserInterface(UserInterfaceComponent::InputPanel);
}

void ShanjieClient::hideCandidates() {
    ic_->inputPanel().setCandidateList(nullptr);
    ic_->updateUserInterface(UserInterfaceComponent::InputPanel);
}

bool ShanjieClient::isPassword() const {
    return ic_->capabilityFlags().testAny(CapabilityFlag::PasswordOrSensitive);
}

std::optional<std::string> ShanjieClient::leftContext() const {
    if (!ic_->capabilityFlags().test(CapabilityFlag::SurroundingText)) return std::nullopt;
    const SurroundingText &st = ic_->surroundingText();
    if (!st.isValid()) return std::nullopt;
    return shanjie::textBefore(st.text(), st.cursor(), kLeftContextChars);
}

// ---- ShanjieEngine

ShanjieEngine::ShanjieEngine(Instance *instance)
    : instance_(instance), factory_([this](InputContext &ic) { return new ShanjieClient(this, &ic); }) {
    dispatcher_.attach(&instance_->eventLoop());
    readAsIni(config_, kConfPath);
    session_ = std::make_unique<shanjie::Session>(
        findPaths(), toCoreConfig(config_),
        [this](std::function<void()> f) { dispatcher_.schedule(std::move(f)); }, logCode);
    if (!session_->ready()) FCITX_ERROR() << "shanjie: no engine; every key is passed through";
    instance_->inputContextManager().registerProperty("shanjieClient", &factory_);
}

ShanjieEngine::~ShanjieEngine() = default;

void ShanjieEngine::keyEvent(const InputMethodEntry &, KeyEvent &event) {
    if (event.isRelease()) return;
    InputContext *ic = event.inputContext();
    const Key key = event.rawKey();
    shanjie::KeyInput in;
    // Key::code() is the X keycode (evdev + 8); some frontends give 0, then fall back to the keysym.
    in.evdev = key.code() >= 8 ? static_cast<uint32_t>(key.code() - 8)
                               : shanjie::evdevFromKeysym(static_cast<uint32_t>(key.sym()));
    const KeyStates states = key.states();
    in.shift = states.test(KeyState::Shift);
    in.ctrl = states.test(KeyState::Ctrl);
    in.alt = states.test(KeyState::Alt);
    in.super = states.test(KeyState::Super) || states.test(KeyState::Super2);
    in.caps = states.test(KeyState::CapsLock);
    if (session_->handleKey(*ic->propertyFor(&factory_), in)) event.filterAndAccept();
}

void ShanjieEngine::deactivate(const InputMethodEntry &, InputContextEvent &event) {
    InputContext *ic = event.inputContext();
    // On focus-out fcitx5 (or the client) commits the client preedit itself, so committing here too
    // would insert the text twice. Commit only when switching input method, or when the preedit is
    // shown in the panel and nobody else will send it.
    const bool commit = event.type() == EventType::InputContextSwitchInputMethod ||
                        !ic->capabilityFlags().test(CapabilityFlag::Preedit);
    session_->finish(*ic->propertyFor(&factory_), commit);
}

void ShanjieEngine::reset(const InputMethodEntry &, InputContextEvent &event) {
    session_->finish(*event.inputContext()->propertyFor(&factory_), false);
}

void ShanjieEngine::setConfig(const RawConfig &raw) {
    config_.load(raw, true);
    safeSaveAsIni(config_, kConfPath);
    session_->setConfig(toCoreConfig(config_));
}

void ShanjieEngine::reloadConfig() {
    readAsIni(config_, kConfPath);
    session_->setConfig(toCoreConfig(config_));
}

void ShanjieEngine::pick(InputContext *ic, uint32_t index) {
    session_->pick(*ic->propertyFor(&factory_), index);
}
```

## Amendments after review (applied in the code; the task text above predates them)

- `src/fcitx_key.h` holds the fcitx5 key to `KeyInput` conversion (X keycode minus 8, keysym fallback),

  selection is open, and stops if applying the awaited job failed.
- `test_rerank_runner` covers a stale job with the current one behind it; `test_session` covers an

### Second review

- Install path: `FCITX_INSTALL_USE_FCITX_SYS_PATHS` defaults to ON in `CMakeLists.txt` and is passed
